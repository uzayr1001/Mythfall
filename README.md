# Mythfall

A mythological 2D side-scrolling action roguelite for Windows, built with Godot 4 and the Compatibility renderer.

## Current milestone: Ashen Proving Grounds

The first playable combat prototype focuses on responsive movement and readable combat before expanding into procedural runs, weapons, bosses, and progression.

### Included in this build
- Acceleration-based movement, double jump, and directional dash.
- Sword strike with a short active hit window.
- A basic Ash Hound enemy that pursues and attacks the player.
- Three-point vitality, damage feedback, knockback, death, and restart.
- A handcrafted test arena and minimal HUD.

### Controls
| Action | Keyboard |
|---|---|
| Move | A / D or Left / Right |
| Jump / Double jump | Space or W |
| Sword attack | J or Left mouse button |
| Dash | Left Shift or K |
| Restart after defeat | R |

## Run it
1. Install Godot 4.x.
2. Download or clone this repository.
3. Open the folder containing project.godot in Godot.
4. Press F5 to run the project.

## Technical target
- Windows 10+
- Godot 4.x
- Compatibility renderer (OpenGL), chosen for broad support and the Intel HD 4600 class of hardware.

## Development direction
1. Movement and combat feel.
2. Enemy variety and a first multi-phase boss.
3. Handcrafted room set and procedural room sequencing.
4. Weapon archetypes and abilities.
5. Run progression, campaign structure, and endless mode.
6. Original visual effects, sound, music, and performance polish.

Mythfall is being developed incrementally. Each milestone should remain playable and be tested before the next layer is added.
